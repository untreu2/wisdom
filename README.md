# Wisdom - Note-Taking App

A cross-platform note-taking app built with Flutter. Wisdom provides a clean and simple interface for capturing and organizing your notes, with secure local storage powered by Hive.

## Features

- Create, edit, and delete notes
- Local-first storage with Hive for fast, offline access
- Secure storage for sensitive data
- Image attachment support
- Clean, Material Design-based UI with custom Google Fonts

## Tech Stack

- **Framework:** Flutter (Dart)
- **Local Storage:** Hive / Hive Flutter
- **State Management:** Provider
- **Platforms:** iOS, Android, Web, macOS, Linux, Windows

## Getting Started

1. Ensure you have [Flutter](https://flutter.dev/docs/get-started/install) installed (SDK ^3.7.2).
2. Clone the repository and install dependencies:
   ```bash
   git clone https://github.com/untreu2/wisdom.git
   cd wisdom
   flutter pub get
   ```
3. Run the app:
   ```bash
   flutter run
   ```
